UPLOAD:
Upload the entire contents of this folder (or the ZIP) to your website host.
For Netlify:
1. Open Netlify.
2. Choose Add new project / Deploy manually.
3. Drag the ZIP's extracted folder contents into the deploy area, or use the folder if your Netlify interface supports it.
4. Make sure index.html is at the top level.
5. After deployment, open the public URL and test the WhatsApp, Call, email, social links and map.
